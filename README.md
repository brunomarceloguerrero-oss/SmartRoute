# SmartRoute 🚗

SmartRoute es un proyecto desarrollado en C++ con el objetivo de aprender
programación, algoritmos y optimización de rutas.

## Versión actual

v0.1

## Funcionalidades actuales

- Registro de 5 destinos.
- Validación de distancias.
- Cálculo de distancia total.
- Cálculo de distancia promedio.
- Identificación del destino más cercano.
- Identificación del destino más lejano.

## Objetivo

El objetivo de SmartRoute es evolucionar progresivamente hacia un sistema
capaz de analizar múltiples destinos y encontrar rutas más eficientes
utilizando algoritmos de optimización.

## Tecnologías

- C++
- Visual Studio
- Git
- GitHub

## Próximos pasos
